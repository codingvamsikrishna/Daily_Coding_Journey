# CSV Handling

This folder contains examples of reading, writing, and analyzing CSV files using Pandas.

## Files

| File Name | Description |
|------------|-------------|
| employees.csv | Sample employee dataset |
| read_csv.py | Read CSV file |
| write_csv.py | Create a new CSV file |
| read_selected_columns.py | Read specific columns |
| skip_rows.py | Skip rows while reading |
| save_dataframe.py | Save filtered data |
| employee_analysis.py | Analyze employee data |

## Topics Covered

- read_csv()
- to_csv()
- Selecting columns
- Skipping rows
- Saving DataFrames
- Basic CSV analysis
