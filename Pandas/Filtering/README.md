# Pandas Filtering

This folder contains examples of filtering data in Pandas.

## Files

| File Name | Description |
|------------|-------------|
| sample_data.csv | Sample dataset |
| single_condition.py | Filter using one condition |
| multiple_conditions.py | Multiple conditions |
| isin_method.py | Using isin() |
| between_method.py | Using between() |
| string_filter.py | Filter text values |
| query_method.py | Using query() |

## Topics Covered

- Boolean Indexing
- Multiple Conditions
- isin()
- between()
- String Filtering
- query()
