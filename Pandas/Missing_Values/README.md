# Missing Values

This folder contains examples of handling missing values in Pandas.

## Files

| File Name | Description |
|------------|-------------|
| employees.csv | Sample dataset with missing values |
| check_missing_values.py | Find missing values |
| drop_missing_values.py | Remove missing values |
| fill_missing_values.py | Replace missing values with text |
| fill_with_mean.py | Fill numeric values using mean |
| fill_with_median.py | Fill numeric values using median |
| replace_missing_values.py | Replace missing values in a specific column |

## Topics Covered

- isnull()
- dropna()
- fillna()
- mean()
- median()
- Handling missing values
