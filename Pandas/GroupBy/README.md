# GroupBy

This folder contains examples of grouping and aggregating data using Pandas.

## Files

| File | Description |
|------|-------------|
| basic_groupby.py | Create groups |
| groupby_sum.py | Total salary |
| groupby_mean.py | Average salary |
| groupby_count.py | Employee count |
| groupby_multiple_columns.py | Maximum salary |
| groupby_agg.py | Multiple aggregations |

## Topics Covered

- groupby()
- sum()
- mean()
- count()
- max()
- min()
- agg()
