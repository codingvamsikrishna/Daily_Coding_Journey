# Pandas DataFrame Basics

This folder contains beginner-friendly Pandas examples for Data Analysis.

## Files

| File Name | Description |
|------------|-------------|
| create_dataframe.py | Creating a DataFrame |
| read_csv.py | Reading CSV files |
| select_columns.py | Selecting columns |
| select_rows.py | Using head() and tail() |
| dataframe_info.py | DataFrame information |
| dataframe_statistics.py | Statistical summary |
| employee_analysis.py | Basic employee analysis |
