# Tuples

This folder contains Python tuple examples and practice programs.

## Files

| File Name | Description |
|---|---|
| tuple_creation.py | Creating tuples |
| tuple_indexing.py | Accessing tuple items |
| tuple_slicing.py | Tuple slicing example |
| tuple_methods.py | Tuple methods usage |
| tuple_packing_unpacking.py | Packing and unpacking |
| loop_through_tuple.py | Looping through tuple |
| tuple_to_list.py | Converting tuple to list |

## Topics Covered

- Tuple creation
- Indexing
- Slicing
- Tuple methods
- Packing & unpacking
- Loops with tuples
