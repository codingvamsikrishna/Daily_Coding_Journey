# File Handling

This folder contains Python file handling examples and mini practice programs.

## Files

| File Name | Description |
|---|---|
| write_file.py | Writing data into file |
| read_file.py | Reading file content |
| append_file.py | Appending data into file |
| read_lines.py | Reading file line by line |
| file_exists_check.py | Checking file existence |
| word_count.py | Counting words in file |
| student_record.py | Saving student records |

## Topics Covered

- File opening
- Write mode
- Read mode
- Append mode
- File methods
- Word count
- Record saving
